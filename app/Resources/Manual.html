jusage

jusage sits in the menu bar and shows how much of your Claude plan you have used: the 5-hour session and the 7-day week, for every Claude Code account on this Mac. Click it for the panel.

The menu bar

The title shows the meters you chose in Settings. Hover it for each account's detail. A grey title means the reading is old (15 minutes or more) or a reset is due. Right-click the icon for About, Check for Updates, Quick Keys, Send Report, this Manual, What's New, Run Doctor, Licenses, Uninstall and Quit.

Colours

Green: you are keeping up with the clock or ahead of it. Amber: you have used more than the share of the period that has gone. Red: 97% or more used. The forecast never colours anything.

Settings

Check every (15 seconds to 10 minutes), the status-line backup per account, the menu bar tags, colour by the worst meter, the accent colour, Open at login.

Status-line backup. When it is on, jusage reads your usage from Claude Code's own replies and asks Anthropic only when no reply has arrived for a while. Turning it off puts your original Claude Code status line back exactly.

Quick Keys

⇧⌃K lists every shortcut. Click one and press the new keys. Refresh is ⌘R, Open Dashboard ⌘D, Previous and Next Month ⌥← and ⌥→. Settings (⌘,) and Quit (⌘Q) are fixed.

Updates

jusage checks for a new version once each time it opens, and every day while it runs. App menu › Check for Updates… checks right now.

Reporting a problem

Help › Send Report… opens Mail with the log attached, addressed to contact@fourletterrecords.com. Help › Run Doctor shows what is healthy and what needs fixing; it never prints a login or a key.

Uninstalling

Right-click the icon › Uninstall jusage… First jusage gives Claude Code its original status line back, switches off Open at login and removes its line from your shell files. Then everything goes to the Trash, never deleted outright. "Keep my settings" leaves ~/.claude-usage (your usage history and settings) in place.

In Terminal, jusage uninstall restores the status line and moves jusage to the Trash. The script on its own does only the moving, so restore the status line first:

jusage statusline off --all
sh "/Applications/jusage.app/Contents/Resources/uninstall.sh"
